\# Local RAG Knowledge Assistant



\## Overview



This project is a local Retrieval-Augmented Generation (RAG) prototype for answering questions based on PDF documents.



The application processes documents, creates embeddings, performs similarity search, and generates answers using a locally hosted language model.



\## Features



\- PDF document processing

\- Text chunking and embedding generation

\- Vector search

\- Question answering with a local LLM

\- Streamlit-based user interface



\## Technologies



\- Python

\- Streamlit

\- LangChain

\- FAISS

\- Ollama
